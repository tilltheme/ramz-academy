# أكاديمية رمـز — الموقع

موقع تعريفي بأكاديمية رمـز (مبادرة تعليمية من رمـز لأتمتة الأعمال) ومذكراتها. أول مذكرة: «أتمتة الأعمال من الصفر» بقلم مهجه الصبحي — الجزء الأول.

الهوية نفسها هوية «نشرة رمـز الأسبوعية»: خط Alan Sans فقط، الورق `#F2EFE8` والحبر `#141413` والبرتقالي `#FF5A1F` للإشارة، والشكل الداكن الناعم مع الجيب الفاتح، وشعار رمـز البرتقالي بلا إعادة رسم.

## البنية

```
site/                         ← هذا اللي ينشر (مجلد النشر في الاستضافة)
  index.html                  الرئيسية: عن الأكاديمية، أحدث المذكرات، اقتباسات، طريقتنا، من نحن
  memos/index.html            كل المذكرات
  memos/<slug>/index.html     صفحة المذكرة وأجزاؤها
  memos/<slug>/part-<n>/      الجزء: index.html للقراءة، book.html كتاب يُقلَّب ويُطبع، وملف PDF
  assets/catalog.js           قائمة المذكرات وأجزائها واقتباساتها، وروابط الأكاديمية
  assets/site.css · site.js   التنسيق والأجزاء المشتركة (الترويسة، الفوتر، البطاقات، الشكل الداكن)
  assets/resume.js            «كمّل من حيث وقفت» و«احفظ مكاني»
  assets/highlights.js        التظليل والملاحظات
  assets/fonts/  assets/brand/  الخط والشعار والأيقونة وصورة المشاركة
  404.html · robots.txt
tools/                        أدوات الفحص والبناء (لا تُنشر)
```

الموقع ملفات ثابتة بلا بناء: أي تعديل في `site/` ينشر كما هو.

## النشر
- في الاستضافة (Cloudflare Pages أو Netlify أو غيرها): اربط هذا المستودع، واترك أمر البناء فاضي، واجعل **مجلد النشر `site`**.
- اجعل النشر من فرع الإنتاج فقط (`main`)، وخلّ التعديلات تمر على فرع ثاني أو معاينة قبل الدمج — كذا كل تعديل يُراجع قبل ما يوصل للموقع.
- بعد ما يتحدد العنوان (نطاق فرعي لرمـز):
  ```
  node tools/set-url.js https://academy.<نطاق رمـز>
  ```
  يضيف الروابط الكاملة لصورة المشاركة و`canonical` و`sitemap.xml` — منصات التواصل ما تعرض صورة المشاركة بدونها.

## تعديلات شائعة
- **إضافة روابط الأكاديمية:** في `site/assets/catalog.js` داخل `links` — ضع الرابط، فيظهر زره تلقائيًا (عمود «تابعنا» في الفوتر وأزرار «من نحن»). الفاضي يبقى مخفي.
- **نشر جزء جديد:** مجلد `part-<n>/` بصفحة القراءة وكتابها وPDF، ثم أضف للجزء في `catalog.js`: `chapters` و`pages` و`read` و`book` و`pdf` — فيتحول من «قريبًا» إلى جزء منشور في كل مكان.
- **مذكرة جديدة:** مجلد `memos/<slug>/` (نسخة من صفحة المذكرة الأولى مع تغيير `data-article`) وأجزاؤها، ثم إدخال في `memos` داخل `catalog.js` مع اقتباساتها في `quotes` — فتظهر في الرئيسية وصفحة المذكرات والفوتر، واقتباساتها في الرئيسية باسم مذكرتها.
- **بعد تعديل صفحات الكتاب:** `npm run pdf` يعيد بناء ملف PDF وغلاف المذكرة.

## الفحص قبل النشر
```
npm install && npx playwright install chromium
npm run check              # كل صفحة على الكمبيوتر والجوال: لا أخطاء، الخط Alan Sans فقط، الصور والروابط سليمة، لا شيء من خارج الموقع
npm run check-resume       # «كمّل من حيث وقفت» من البداية للنهاية
npm run check-highlights   # التظليل والملاحظات: لابتوب ← كتاب ← جوال
npm run tour               # فيديو جولة الزائر في tools/out/tour.mp4
```

## الخصوصية
لا حسابات ولا تتبع ولا خوادم: مكان القارئ وتظليلاته تنحفظ في متصفحه فقط، وتنتقل لجهاز ثاني داخل الرابط اللي يرسله لنفسه.
