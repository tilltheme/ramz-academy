# نشر الأكاديمية على خادم رمز في SCCC — بدون المساس بموقع رمز

**القرار:** الأكاديمية موقع ثابت بالكامل: لا Node، ولا خدمة، ولا منفذ، ولا قاعدة بيانات، ولا تجمع أي بيانات من الزوار (مكان القارئ وتظليلاته في متصفحه فقط). فحسب دليل النشر: **نفس خادم رمز مقبول**، وnginx يقدّم ملفاتها مباشرة من `/srv/academy`.

## اللي يضيفه النشر — وبس
| الشي | المكان |
|---|---|
| ملفات الموقع | `/srv/academy/releases/<وقت>/` و`/srv/academy/site` (رابط لآخر إصدار) |
| مجلد التحقق للشهادة | `/srv/academy/acme/` |
| ملف nginx جديد للاسم `academy.ramz.net.sa` فقط (بدون `default_server`) | `/etc/nginx/sites-available/` + رابطه في `sites-enabled/` (أو `conf.d/` حسب الخادم) |
| شهادة للأكاديمية فقط | `/etc/letsencrypt/live/academy.ramz.net.sa/` |
| سجلاتها | `/var/log/nginx/academy.*.log` |
| نسخة احتياطية من `/etc/nginx` قبل أي تعديل | `/root/nginx-backup-<تاريخ>` |
| ملاحظات الفحص | `~/academy-deploy/` |

**ما ينلمس أبدًا:** ملفات رمز، `server/` و`.env`، طلبات العملاء، ملف nginx الخاص برمز، شهاداته، خدمته، DNS حقه. لا `restart` لـnginx (reload فقط بعد نجاح `nginx -t`)، لا تحديثات عامة، لا تغيير جدار ناري.

## الخطوات (على الخادم، بالمستخدم الإداري المعتاد)
```bash
git clone https://github.com/tilltheme/ramz-academy ~/ramz-academy && cd ~/ramz-academy
```

1. **Snapshot** للخادم من لوحة SCCC.
2. **جرد للقراءة فقط + خط الأساس لرمز:**
   ```bash
   bash deploy/1-inventory.sh
   ```
   راجع `~/academy-deploy/inventory.txt` وأرسل ملخصه (بدون أسرار). إذا ما كان خادم الويب nginx نوقف هنا ونعدّل الخطة.
3. **التركيب** — يسأل قبل كل تغيير، ويفحص رمز بعدها:
   ```bash
   bash deploy/2-install.sh
   ```
4. **DNS:** المالك يضيف سجل **A** للاسم `academy` على عنوان الخادم. سجلات `ramz.net.sa` و`www` ما تتغير.
5. **الشهادة** — لما يوصل الاسم للخادم:
   ```bash
   bash deploy/3-certificate.sh
   ```
6. **الفحص** بعد كل خطوة (السكربتات تشغّله لحالها، وتقدر تشغّله أي وقت):
   ```bash
   bash deploy/check-ramz.sh [اسم-خدمة-رمز]
   ```

## التحديثات بعدين
التعديلات تمر على GitHub وتُراجع، وما تنشر إلا بعد ما تندمج في `main`. بعدها على الخادم:
```bash
bash deploy/update.sh          # ينزّل آخر main وينقل الموقع له (nginx ما ينلمس)
bash deploy/update.sh --back   # يرجع للإصدار السابق فورًا
```

## التراجع الكامل
```bash
bash deploy/rollback.sh
```
يشيل ملف الأكاديمية من nginx (ثم `nginx -t` و`reload`)، ويسأل قبل حذف `/srv/academy`. وإذا لزم: نسخة `/root/nginx-backup-*` أو لقطة SCCC.

## جُرّب قبل التسليم
ملفّا nginx شغّلناهم في nginx 1.24 جنب «موقع رمز» تجريبي كخادم افتراضي:
- كل اسم يروح لموقعه، وأي اسم غريب يروح لرمز — الأكاديمية ما تخطف شي.
- HTTP يحوّل لـHTTPS، ومجلد التحقق للشهادة يرد، و404 الأكاديمية تظهر، والخطوط تتخزّن أسبوع.
- الموقع كامل في متصفح حقيقي مع ترويسات الأمان (CSP): كل الصفحات، والكتاب، والتظليل ورابطه، والتذكير — بدون ولا تحذير.

## الخصوصية
الأكاديمية ما تجمع بيانات شخصية ولا ترسل شي لأي خادم، فما تحتاج نماذج ولا قاعدة بيانات. لو انضاف لها تسجيل أو نماذج مستقبلًا، تحتاج سياسة خصوصية خاصة فيها.
